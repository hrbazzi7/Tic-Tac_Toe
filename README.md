# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game written in C++, played in the console.

## How to Play
- Played on a 3x3 grid.
- Two players take turns choosing a cell to place their mark (X or O).
- First to get three in a row — horizontally, vertically, or diagonally — wins.
- If the board fills up with no winner, it's a draw.

## How to Build and Run
Open the project in Visual Studio 2022 and press Run, or compile with g++:

    g++ -o tic-tac-toe Main.cpp
    ./tic-tac-toe
